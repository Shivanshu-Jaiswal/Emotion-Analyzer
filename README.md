# Emotion-Analyzer
Machine Learning based Emotion Analyzer using TF-IDF, Logistic Regression and Streamlit.

## Features
- Text emotion prediction
- TF-IDF text vectorization
- Logistic Regression classifier
- Confidence score
- Streamlit web interface

## Emotions
- Sadness
- Anger
- Love
- Surprise
- Fear
- Joy

## Technologies
- Python
- Scikit-learn
- NLTK
- Streamlit
